Eval Run Comparator
Compare baseline and candidate results by case ID. Files are processed in your browser.
File format

Use CSV headers id,status,detail or a JSON array of objects with those fields. Each ID must be unique within its run. Use pass or fail for status. Detail is optional. JSON cases may include an optional trace object using the Trace Inspector format.

[{"id":"incident-report","status":"fail","detail":"Data loss finding changed"}]

Trace Inspector
Find the first agent step that dropped or changed a required field. Trace JSON stays in your browser.
File format

Provide an expected object and ordered steps. Each step needs a name and a fields object. Use strings, numbers, booleans, or null as field values. An optional type labels the step, such as Handoff or Tool call.

{"expected":{"data_loss":false},"steps":[{"name":"Triage","fields":{"data_loss":"unknown"}}]}
